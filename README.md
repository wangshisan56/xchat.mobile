# XChat 中文指南

面向中文用户整理 **XChat 下载、安装、群组目录、X 账号登录、连接排查、常见问题与官方来源** 的非官方使用指南。

这个项目的重点不是做“消息搬运”，而是把中文用户最容易卡住的几个问题讲清楚：

- XChat 到底从哪里下载
- XChat 相关群组和主题入口去哪里找
- 中国大陆用户第一步应该先准备什么
- X 账号和 XChat 的关系是什么
- 为什么有人装好了还是登录不了
- 页面打不开、消息发不出时应该先排查什么

## 在线访问

- 网站首页：https://www.xchat.mobile
- 下载与安装说明：https://www.xchat.mobile/download
- 新手教程：https://www.xchat.mobile/tutorials
- 群组目录：https://www.xchat.mobile/groups
- 网络排查：https://www.xchat.mobile/network
- 常见问题 FAQ：https://www.xchat.mobile/faq

## 这个站适合谁

如果你属于下面这些情况，这个站会更有帮助：

- 想确认 **XChat 官方入口** 是什么
- 想知道 **中国大陆用户应该怎么开始**
- 想按步骤完成 **下载、登录和首次使用**
- 想先找到 **XChat 相关群组、主题入口和公开讨论方向**
- 已经遇到 **打不开、登录失败、连接不稳定** 等问题
- 想快速看懂 **XChat、X 账号、官方帮助中心** 之间的关系

## 这个站提供什么

### 1. 下载与安装路径

把下载入口、使用顺序和常见误区拆开讲清楚，尽量减少用户一开始就走错路径。

### 2. 分步骤新手教程

把“准备什么、先做什么、后做什么”按顺序整理成中文教程，适合第一次接触 XChat 的用户。

### 3. 群组目录与发现入口

把适合中文用户继续深入的群组方向、主题入口和公开讨论线索整理出来，方便用户在完成下载和登录后继续找到可加入的讨论场景。

### 4. 登录与连接排查

专门处理：

- App Store 打不开
- X 账号准备不完整
- XChat 登录异常
- 消息发不出
- 页面加载不稳定

### 5. 常见问题整理

把安装、登录、平台支持、PIN、群组目录等高频问题集中到 FAQ 页面里。

### 6. 官方来源核验

站内尽量把结论和来源分开写清楚，减少“听说”“搬运”“未核验转述”。

## 为什么要做这个站

XChat 相关信息的一个现实问题是：

- 很多讨论只讲结论，不讲路径
- 很多内容面向英文用户，不适合中文新手直接照做
- 很多问题其实不是应用本身，而是入口、账号和连接环境混在一起导致的

这个站的目标不是替代官方，而是做一份 **更适合中文用户理解和执行的整理版说明**。
